## 3. 调试中确认的根因

1. **core1 SS=0**：新系统线程内 `mov %%ss` 读到 0；已通过固定 ring0 长模式 SS（`0x18/0x493`）绕过。
2. **直映射页 NX**：`MmAllocateContiguousMemory` 返回的 Windows 直映射页默认 NX，guest 从复制页取指导致 VMware “invalid part of memory”。最终测试 guest 回到驱动 `.text` 执行。
3. **NPT 私有页剔除在 VMware 嵌套 SVM 下不可用**：剔除 NPT 自页/VMCB/hsave 等会让 VMRUN 崩溃；保留代码但默认关闭，等裸机/KVM 验证。
4. **0xC2 BAD_POOL_CALLER**：`g_guest_code_page=NULL` 时仍调用 `MmFreeContiguousMemory`；所有相关释放已加 NULL 保护。
5. **KD reset 启动期 0xD1**：带 `.reload` 的 KD 在 reset 后 `KdInitSystem/DbgLoadImageSymbols` 触发 0xD1；已从 `kd_ctl.ps1` 去掉自动 `.reload`。
